# Documentation archive

This directory preserves historical implementation notes and delivery artifacts that are no longer part of the active OVRLD Web documentation.

- `legacy-gym-crew/` contains pre-OVRLD patch notes and file manifests.
- `implementation-phases/` contains earlier phase-specific design and implementation notes.

These files are retained for traceability. They are not current deployment instructions and should not be used as the source of truth for the active backend or release process.
