# OVRLD app icons

Pass 2 introduces the OVRLD progression mark: an open training loop crossed by an ascending load bar/arrow. The mark is designed to stay recognizable at favicon, home-screen and in-app sizes.

- `icon-192x192.png` — standard PWA icon
- `icon-512x512.png` — high-resolution PWA icon
- `icon-maskable-512x512.png` — full-bleed maskable Android icon
- `apple-touch-icon.png` — iOS home-screen icon
- `/brand/ovrld-mark.svg` — vector brand mark

Brand accent: emerald/mint. Both light and dark UI themes remain supported.
